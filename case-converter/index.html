Detailed conversion guide

How Case Converter Works

Prose modes preserve punctuation and spacing. Identifier modes extract Unicode letter and number tokens, lowercase them and join them with the chosen convention.

Sentence mode capitalizes after the start or sentence punctuation. Title mode capitalizes each word-like segment; these are deterministic English-oriented rules.

Formats, Boundaries and Limitations

Case Converter Validation Decisions

Automatic title and sentence casing cannot apply every style guide, acronym rule, locale rule or proper-name exception.

Identifier conversion is lossy: punctuation and original word boundaries are normalized, and different inputs can produce the same identifier.
