How to Convert Decimal to Base36

Base36 uses ten decimal digits and 26 letters. Their values run from 0 through 35, so decimal 35 becomes Z and decimal 36 becomes 10. Repeated division by 36 yields the output digits; 46655 is ZZZ.

The full decimal string is parsed as BigInt before formatting in base 36. Values above 2^53 − 1 stay exact. Uppercase and lowercase outputs represent the same integer, which is useful when checking compact numeric IDs.

Exact Decimal to Base36 in JavaScript

The algorithm validates the representation before exact integer conversion, so malformed input never produces a plausible partial answer.

const digits = input.trim().replace(/[\s_]/g, "");
if (!/^[0-9]+$/.test(digits)) throw Error("Invalid decimal");
const base36 = BigInt(digits).toString(36).toUpperCase();

Numeric IDs, Case, and Unsupported Input

This is an integer representation converter. It does not encrypt IDs or encode arbitrary text. Signs, fractional values, and scientific notation such as 1e3 are rejected without a partial result.

Leading decimal zeros are discarded because the output describes a value, not a fixed-width identifier. Spaces and underscores join digits. Use the reverse Base36 to Decimal tool to verify the value; do not use parseInt for integers beyond Number precision.
