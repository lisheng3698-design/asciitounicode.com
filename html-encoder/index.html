Detailed conversion guide

How HTML Encoder Works

Named mode replaces &, <, >, double quote and apostrophe. Numeric mode also emits decimal references for non-ASCII Unicode scalar values.

Encoding text prevents those characters from being interpreted as markup when inserted into an HTML text or quoted attribute context.

Formats, Boundaries and Limitations

HTML Encoder Validation Decisions

Escaping is context-specific. This output is not a complete HTML sanitizer and does not make unsafe URLs, CSS or JavaScript contexts safe.

Unpaired UTF-16 surrogates are rejected. Existing entities are escaped again because the input is treated as literal text.
