How Remove Duplicate Words Works

The tokenizer recognizes Unicode letters and numbers with combining marks, apostrophes, underscores and hyphens inside tokens.

A set records each comparison key while scanning from left to right. The first token is kept and later duplicates are removed.

Remove Duplicate Words Validation Decisions
