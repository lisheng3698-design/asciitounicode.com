Detailed conversion guide

How Reverse Lines Works

The line array is reversed while each record’s characters and internal whitespace remain unchanged.

Final-newline mode preserves a newline only when the input had one; the other mode always removes it.

Formats, Boundaries and Limitations

Reverse Lines Validation Decisions

This changes record order and normalizes line endings, so it is unsuitable for byte-exact binary or signed files.

A blank line is a real record and moves with the other lines; duplicate lines are not removed.
