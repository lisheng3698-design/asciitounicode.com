Detailed conversion guide

How Sort Words Works

Alphabetical and natural modes use an English Intl.Collator with case-insensitive comparison. Natural mode treats digit runs as numbers.

Length mode counts UTF-16 code units for each token and sorts shortest first. Equal values retain their original order.

Formats, Boundaries and Limitations

Sort Words Validation Decisions

Punctuation and original spacing are discarded. This is a token sorter, not a locale-specific dictionary or full linguistic segmenter.

Inputs without Unicode word tokens are rejected. Duplicate tokens remain unless another tool removes them.
