How URL Decoding Works

A percent escape represents one byte. Decoding %20 gives a space, while %E4%BD%A0 is the UTF-8 byte sequence for 你. This tool decodes exactly one layer, so %252F becomes %2F.

Percent decoding leaves a literal + as +. For application/x-www-form-urlencoded values, use form mode to treat a literal + as a space before percent decoding. An encoded %2B still becomes a plus in either mode.

Decode a URL Component in JavaScript

Choose the mode based on how the source was encoded. Decode a single query value after separating it from the query string.

const formEncoded = false;
const decoded = decodeURIComponent(
  formEncoded ? input.replace(/\+/g, " ") : input
);

Malformed Escapes and URL Delimiters

The tool rejects a percent sign without two hex digits and invalid UTF-8. Enter %25 to encode a literal percent sign. It does not guess a legacy character encoding.

Decoding a whole URL for reading can turn %26 into & or %2F into /. Split the URL into components before decoding if you plan to reconstruct a request. Decoding does not open the pasted URL.
