Detailed conversion guide

How UTF-8 Decoder Works

The selected representation is parsed into values from 0 to 255. TextDecoder then decodes with fatal error handling and no replacement characters.

Strict UTF-8 rejects isolated continuation bytes, truncated sequences, overlong encodings, surrogate encodings and values above U+10FFFF.

Formats, Boundaries and Limitations

UTF-8 Decoder Validation Decisions

This is a byte decoder. A Unicode code point such as 1F680 is not itself a UTF-8 byte sequence.

A leading UTF-8 BOM is ignored by the browser decoder. Other encodings such as Latin-1 and UTF-16 are unsupported.
